# 🌍 Travel

> Современная платформа для поиска направлений, бронирования туристических услуг и связи путешественников с проверенными поставщиками.

## ✨ О проекте

**Travel** — это полноценный портал для бронирования туристических услуг.  
Проект создан для демонстрации навыков веб-разработки и архитектуры современных приложений.

## 🚀 Возможности

- 🔍 **Поиск направлений** — удобный каталог туристических локаций
- 📅 **Бронирование услуг** — система резервирования туров и экскурсий
- 🤝 **Связь с поставщиками** — прямой контакт с проверенными партнёрами
- 👤 **Личный кабинет** — управление бронированиями и профилем
